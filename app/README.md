# Папка для установки приложения

Положите сюда билд приложения Novakid для iOS:

- **Симулятор:** `Novakid.app` (или любой `.app` из Xcode/Archive)
- **Устройство:** `Novakid.ipa` (или любой `.ipa`)

Тесты при запуске будут **устанавливать приложение из этой папки** (если указан путь к файлу или найден единственный .app/.ipa в этой папке).

Имя файла по умолчанию: `Novakid.app` или `Novakid.ipa`.  
Либо задайте путь вручную: `-Dapp.path=app/YourBuild.app` или переменная окружения `APP_PATH`.
